# Design System

UI is built from the repo's theme and shared components. Find them first: the theme, token or style files, the UI library in the dependency manifest, the shared components folder.

- Flag colors, spacing, sizes, fonts, breakpoints and shadows hard-coded where the theme names them.
- Flag one-off styles a variant or option already gives.
- Flag custom components redoing what the library or a shared component does, naming the one to use.
